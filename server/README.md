# Сервер Svit — як дати людям Svit Editor на твоєму ключі

Твій ключ Claude ніколи не потрапляє в програму. Він лежить лише на маленькому сервері
(Cloudflare Worker, безкоштовний тариф). Програма звертається до сервера з **кодом доступу**
`svit-…`, а сервер сам підставляє справжній ключ.

- Якщо код витече, ти просто прибираєш його зі списку, і він перестає працювати. Ключ Claude лишається в безпеці.
- Сервер пропускає лише запити монтажу (`/v1/messages`, `count_tokens`, `models`).
- Кожна людина отримує свій код, тож будь-кого можна відключити окремо.

## 1. Окремий ключ із лімітом (5 хв)
1. platform.claude.com → **Settings → Workspaces** → створи workspace `svit-friends`.
2. У ньому **Limits → Spend limit**: наприклад, $20 на місяць. Вище цієї суми сервер не витратить навіть у найгіршому разі.
3. **API keys → Create key** у цьому workspace. Скопіюй `sk-ant-…`, він знадобиться в кроці 2.

## 2. Сервер на Cloudflare (10 хв, без терміналу)
1. Зареєструйся на dash.cloudflare.com (безкоштовно).
2. **Workers & Pages → Create → Create Worker** → назва `svit-editor` → **Deploy**.
3. **Edit code** → видали все → встав увесь вміст `server/worker.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add**, обидва з типом **Secret**:
   - `ANTHROPIC_API_KEY` = ключ із кроку 1;
   - `ACCESS_CODES` = список кодів, наприклад:
     ```json
     {"svit-7f3k9q2m8x4w1c6v5b0n": {"name": "Оля", "per_day": 300}}
     ```
5. Скопіюй адресу воркера (типу `https://svit-editor.ІМʼЯ.workers.dev`) і надішли її Claude.
   Він вшиє її в програму (`SERVER_URL` в `app/engine.py`) і збере нову версію.
   Відкрий цю адресу в браузері: має з'явитися `Svit Editor server: OK`.

Новий код можна згенерувати в Терміналі: `echo "svit-$(openssl rand -hex 12)"`.

### Необов'язково: добові ліміти
**Storage & Databases → KV → Create** (назва `svit-usage`), потім у воркері
**Settings → Bindings → Add → KV namespace**, назва прив'язки **`USAGE`**. Відтоді працює
`per_day` (скільки запитів на добу дозволено коду). Один монтаж — це приблизно 2–5 запитів.

## 3. Як дати програму людині
**Варіант А: найпростіший для неї.** Особиста збірка з уже вшитим кодом:
```bash
SVIT_ACCESS_CODE=svit-7f3k9q2m8x4w1c6v5b0n bash build.sh
```
З'явиться `dist/Svit Editor <версія> (особиста — не публікувати).zip`. Передай його особисто
(Telegram тощо). **Не клади цей файл у `release/`**: GitHub-публікація все одно його відхилить.
Наступні оновлення людина отримуватиме звичайним шляхом, код у неї залишиться.

**Варіант Б.** Людина ставить звичайний реліз з GitHub, а код вставляє у вікні ключа
(або пізніше: Налаштування → «Оновити API ключ»).

## Відключити людину
Cloudflare → воркер → Settings → `ACCESS_CODES` → прибери її рядок → Save. Діє одразу.
Якщо щось виглядає підозріло, видали також ключ у Claude Console і створи новий.

## Чесно про межі
- Людина з кодом може користуватися Claude через твій сервер. Від зловживань захищають ліміт workspace і `per_day`.
- Сам ключ `sk-ant-…` з програми не дістати, бо його там немає.
