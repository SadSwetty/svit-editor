# Svit Film — аудит відносно FILM_EMULATION_MASTER_SPEC (26.11.2026)

## Було (1.x)
- OpenFX-плагін (C++, CPU, багатопотоково), хост — DaVinci Resolve; GPU-бекенду немає.
- Входи: Rec709 γ2.4, DaVinci Intermediate, S-Log3, LogC3 — лише передавальні функції, без матриць гамуту.
- 8 «образів» як сигмоїди в дисплейному просторі; щільності, друку, профілів даних немає.
- Halation з жорстким порогом (додавання світла), зерно — value-noise у дисплейному просторі.
- Тестів ядра не було (лише minihost для OFX-протоколу).

## Зроблено (2.0)
- Схема профілів (`profiles/`), 20 плівок зйомки + 3 друку + нейтральні референси, валідатор і генератор
  (`tools/gen_profiles.py`), матриця покриття (`docs/COVERAGE.md`), маніфест джерел (лише неперевірені ліди).
- Конвеєр §5: вхід → сцена-лінійне (Rec.2020 D65, матриці гамуту для всіх входів) → експозиція/баланс →
  halation/bloom у просторі експозиції зі збереженням енергії → log-експозиція → крива щільності →
  зерно в щільності (фізичний масштаб від апертури 48 мкм і формату) → друк з калібруванням сірого /
  скан / пряме проєктування слайда → дисплей → вихідний простір → Expand.
- Оборотні та ч/б плівки — окремі гілки (щільність падає з експозицією; ч/б — один канал).
- Статус профілю видно в плагіні («Experimental – estimated curves, not measured»).
- Тести ядра: тотожність нейтрального обходу, монотонність для всіх 20×4 комбінацій, калібрування сірого,
  скінченність на NaN/Inf/екстремумах, детермінованість зерна, збереження рівного поля halation,
  напрям кривих, push, blacks/whites.

## Не зроблено / блокери
- Немає жодних оцифрованих даних: усі криві — `experimental_seeds` (оцінки). Потрібні технічні листи.
- Спектральний шлях (§5.3, §5.7–5.8) не реалізований: модель — RGB-щільність.
- MTF, міжшарові ефекти з вимірів, реципрокність, push/pull з даних — немає даних.
- GPU-шлях (Metal/CUDA) відсутній; продуктивність 4K не вимірювалась на Маку.
- Стара DCTL-версія (`Svit Film.dctl`) не оновлена до 2.0.
