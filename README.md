# Svit Editor

AI-монтажер для DaVinci Resolve на Mac. Пишеш словами, що змонтувати, і Claude ріже відео:
підбирає моменти, ставить склейки під біт, кадрує, додає зуми, ефекти, переходи й вінтажні фактури,
а DaVinci одразу збирає готовий таймлайн.

## Встановлення
1. Завантаж `Svit Editor <версія>.zip` зі сторінки [Releases](../../releases/latest) і розпакуй.
2. Відкрий **Svit Editor Installer** → «Встановити».
   Перший раз macOS попросить дозвіл: Системні параметри → Приватність і безпека → «Усе одно відкрити».
3. DaVinci Resolve **Studio** → Workspace → Scripts → **Svit Editor**.
4. Встав свій ключ Claude API (створюється на platform.claude.com).

Оновлення приходять автоматично. Кожне оновлення підписане цифровим підписом автора,
і програма встановлює лише справжні версії.

## Можливості
- монтаж за текстовим запитом, кілька роликів з одного матеріалу;
- монтаж під музику: темп, удари, склейки на біт; lip-sync дублів для кліпів і лірик-відео;
- граматика монтажу, абстрактність ідей, Cinematic mode;
- референси з TikTok / Reels / Shorts / YouTube;
- ефекти, переходи, вінтаж (VHS, плівка, ТБ, lost wave), дрімі-розмиття, halation, автоконтраст;
- правки після монтажу словами, зокрема лише для обраної ділянки;
- українська й англійська мова інтерфейсу.

## Для розробки
- `app/engine.py` — аналіз матеріалу, план монтажу від Claude
- `app/ui.py`, `app/web/` — вікно програми
- `resolve/Svit Editor.py` — частина всередині DaVinci (Python 3.6+)
- `installer/res/` — інсталятор
- `bash build.sh` — збирає підписаний інсталятор у `dist/`.
  Ключ підпису **не зберігається в репозиторії** і передається через `SVIT_SIGN_KEY`.
